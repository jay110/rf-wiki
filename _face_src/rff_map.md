# 边境 / 海洋 头像取材记录

## 一、边境（RFF，Wii）——已接入 31 人

### 源

- 路径：`G:/BaiduNetdiskDownload/边境图片导出/`（305 MB，5819 张 PNG + 4 张 PSD）
- 来源：贴吧 lwyx2014《【资源重发】符文工房边境和海洋图片导出》——
  改进 EveryFileExplorer 后从游戏 rom 批量导出，按导出批次编号建子目录（`00001`、`00915`…）。
- 命名：`FACE<编号>_<表情>_<帧>.png`，例如 `FACE01_N_0.png`。
  表情代号见过 `N`（通常）、`S0`/`S1`（笑/特殊）、`W`、`L`、`N_S`；带 `_R` 后缀的是同图左右翻转。

### 命名的由来

边境的对话立绘是 **480 高、宽度不等** 的半身像（宽 296–568），一人一套多表情：

| FACE 编号 | 表情张数 | 判定 |
|---|---|---|
| 00 | 5 | 主角 ラグナ |
| 01–11 | 9–18 | 花嫁候补（台词多，表情最全） |
| 12 / 13 | 9 / 9 | エリス 白 / 黑（同构图换色，见下） |
| 14–31 | 2–5 | 居民（台词少） |

`FACE12_N_0` 与 `FACE13_N_0` 的 alpha 包围盒完全相同（116,116,404,480）但 md5 不同，
是同一张画换色 —— 对应名册里「艾莉丝（白／黑）双子」一条。

编号与人名的对应采用 **FACE = 站内名册序号 + 1**（名册序号含主角，即 `FACE00` 是第 0 条）。
这个偏移用四条互相独立的角色描述反查过，全部吻合：

| 锚点 | 名册描述 | 落在 | 画面 |
|---|---|---|---|
| ラピス | 教会的修女兼护士 | FACE03 | 深蓝长发、白色修女头巾 |
| ステラ | （名册无描述，CV 斉藤貴美子） | FACE19 | 紫红头巾的老妇 |
| ミネルバ | （名册无描述，CV 鹿野潤） | FACE24 | 戴帽小妖精 |
| つぶて | 自称武蔵大和守 | FACE28 | 白发老人、红袍、抱黑猫 |

另外 `ラピス = Lara`（名册 `e` 字段）与 fandom 的「Lara the nurse」一致，可作英文名侧旁证。

### 已知不确定项

- 居民段（FACE14–31）是按名册顺序推的。四人锚点吻合，但 **FACE23（卢特/ルート）、
  FACE25（克罗斯/クロス）** 的形象与名字的性别感对不上（画上偏女性、名册侧多为男性 CV），
  这两张若要更保险，可对照游戏内名鉴再确认一次。
- 只切了每个编号的「正常表情」一张。多表情（笑/怒/羞）源图没入库，需要时可再补。

### 重建

```bash
python _build_rff_faces.py     # 读 _face_src/rff/FACE##.png → assets/face/rff/<slug>.png
```

裁切参数：方框边长 = alpha 高度 × 0.78，顶边再上移 1.5% 画面高，水平按 alpha 居中，输出 160×160。
`HEAD_RATIO` 偏大时头发会被切、偏小时留白多，按需微调。

## 二、海洋（RFO，PS3）——游戏内没有可用头像，未接入

翻遍 `G:/BaiduNetdiskDownload/海洋图片导出/`（145 MB，3016 张 PNG）后的结论：

| 找过的东西 | 结果 |
|---|---|
| `FACE` 类 | 只有 8 张（`MS350_FACE`、`PC36_FACE`、`PC37_FACE`、`PC38_FACE`、`PC90_FACE`、`PC_W50_2_FACE`、`PC_W51_2_FACE`、`PC03_FACEMAP`），全是 **512×256 的 3D 贴脸 UV 展开图**——一张图上把 6 个角度的脸并排铺开，不能当头像 |
| `LUEV*`（145 张，全 856×480） | 结局房间＋相框里的合影，人物只有指甲盖大 |
| ≥400px 的大图抽样 48 张 | 全是 UI、地图、3D 模型 UV、道具图标，没有一张 2D 立绘 |

原因：海洋是 3D 模型演出，对话没有 2D 立绘这一层美术，所以游戏资源里根本不存在「立绘」。
**要补海洋头像只能走游戏外**：官网（PS3 时期已下线，需 Wayback）、fandom 角色页、或攻略本扫描。

注意：本站点 `FACE` 只覆盖 6 作（rf1–rf5 + rff），rfo 未接入，页面会退回首字色块。
