## 通用教训
- **NDS/DS 图形优先按调色板索引抠图，不要按 RGB 距离**。索引 0 通常就是透明键色，
  硬键控得到硬边但绝对干净；软键控必然产生彩色毛边。
- 4bpp/8bpp 的 `RGCN`/`RLCN` 里，数据区常在 0x30（`CHAR` 块头 0x18 字节后）；
  但**不要照抄**，用「文件长度 − 数据量 = 偏移」反推更可靠。
  本例 49216 − 49152 = 64 = 0x40 是错的（会错位），实际 0x30 才对（尾部还有 `CPRT` 版权块）。
  验证方式：解码后与已渲染的 BMP 比对一致率。
